# Schematics

Architecture and data-shape schematics for Quotagate. Schematics **elaborate** the spec — they never
contradict it. `./quotagate-spec.md` (the spec lives in this directory) is the source of truth; if a schematic and the spec disagree,
the spec wins and the schematic is corrected (or deleted).

## What goes here

- **`components/`** — component and data-flow schematics: how the proxy, router, adapters, MCP client,
  validator, and response builder fit together and how a request flows through them. Examples worth
  authoring as the design firms up:
  - `request_lifecycle.md` — POST /v1/chat/completions → parser → argument builder → router →
    adapter (MCP/subprocess) → validator/retry → response builder → caller (spec §4.2–§4.5).
  - `transport_and_serialization.md` — MCP-primary vs `--print` fallback, the per-session
    serialization lock, and "persist the process, not the conversation" (spec §3.1/§3.8, invariants #10/#11).
  - `constraint_mechanism.md` — the three reinforcing layers: tool definition → `~/.quotagate/CLAUDE.md`
    → tool arguments (spec §3.2).
- **`schemas/`** — data-shape schematics: the exact structures at each seam.
  - `openai_request_response.md` — the OpenAI request fields parsed and the response object emitted
    (the output contract, invariant #5).
  - `quotagate_complete.md` — the `quotagate_complete` tool's arguments + the JSON it returns
    (`{type: "text"|"tool_call", ...}`), with the Zod schema used by the validator (spec §3.5).
  - `adapter_response.md` — the internal `AdapterResponse` type all adapters return.

## Conventions

- One concept per file; lead with a one-line purpose and a link to the relevant spec section.
- Prefer ASCII diagrams + a short prose contract over prose alone — they survive in a terminal and diff cleanly.
- Keep schematics current via `/house-keeping` Step 3 (schematic-sync) whenever a contract changes.
- These are design artifacts, not generated output. The runtime `~/.quotagate/CLAUDE.md` is a product
  output (generated by `src/mcp/claudeMd.ts`) and does **not** belong here.
